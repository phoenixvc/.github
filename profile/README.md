## Overview

Phoenix VC is an AI-native venture studio architecting sovereign multi-agent systems, defense simulations, and interactive storytelling platforms. Led by CTO [Jurie Smit](https://github.com/justaghost).

## Engineering Principles

- **Cognitive Sovereignty**: Zero vendor lock-in, private cloud deployments on Azure Container Apps, and open-source foundation engines.
- **Deterministic Orchestration**: Cryptographic task leases (Baton) and strict verification quality gates (Retort) to eliminate agent hallucination drift.
- **FinOps Telemetry**: Granular token spend tracking and proactive budget containment (Docket & Sluice).
